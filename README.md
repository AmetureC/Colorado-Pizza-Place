# Colorado-Pizza-Place

This project is a web application for Colorado Pizza Place. The Sprint 1 functionality focuses on allowing customers to view the menu, select pizzas, add items to a cart, view the total, and place an order.

## Sprint 1 Features
- Home page
- Menu page
- Pizza selection
- Shopping cart
- Order summary
- Basic checkout/order confirmation

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run the Website

This project is a basic HTML, CSS, and JavaScript website. To open the website locally, open the project folder in a code editor such as Visual Studio Code or GitHub Codespaces.

In the terminal, run:

```bash
python3 -m http.server 8000
